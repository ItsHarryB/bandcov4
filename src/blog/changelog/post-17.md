For the version of this website to change from v0.11.0 to v0.12.0 on 10/03/2026, some changes were made to the formatting, appearance and layout of this website - mainly significant changes to the overall appearance of the site, with the introduction of a new colour scheme - orange! This change applied to the header, links and a new favicon.

Examples of such changes are quite minor for v0.12.0, mainly consisting of the refinement of the overall website, with the alteration of photo carousels in order for them to match being a key change and refinement.

For v0.12.x versions, minor adjustments, fixes and tweaks were made, including backend updates and changes to the website switcher.
