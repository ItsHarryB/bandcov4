Due to the range of changes being made to TEST:Brighton and Co, the versioning scheme has changed from v0.14.0 to v26.3.0.

Previously, the versioning scheme would work as follows:

1. Where the first "**0**" (zero) in v**0**.14.0 would remain unchanged, demonstrating the test nature of the site.
2. With the "**14**" in v0.**14**.0, that would change if there were significant alterations to the website, rendering it in one way or another significantly different to the previous version.

    <ul class="custom-bullets">
      <li>I.e. v0.<b>13</b>.0 to v0.<b>14</b>.0 had significant changes in terms of how the font for the entire site was loaded, rendering it incompatible with previous versions.</li>
    </ul>

3. With the last "**0**" (zero) in v0.14.**0**, that would change if there were minor alterations, such as minor fixes or tweaks that overall have a minimal impact on the functioning and appearance of the site.
4. The last version of this website before the new versioning scheme was v0.14.0**a**. The letter after the last "0", beginning with "**a**" (then so on), is for very minor changes - usually for fixing things that were broken.

<hr class="section-divider" />

The new versioning scheme works as follows:

1. With "**26**" in v**26**.3.0, the "**26**" represents the year (*2026*) of the version/update to the website. This will only change every year (updates/versions in *2027* will be **27**.1.0 and so on).
2. With the "**3**" in v26.**3**.0, the "**3**" represents the month of the version/update to the website. This will change every month depending on new versions/updates (updates/versions in *April* will be v26.*4*.0 and so on).
3. The last "**0**" (zero) in v26.3.**0** will change on if there are significant changes that have a significant impact on the functioning and/or appearance of the website.
4. There will still be a letter "**a**" after the last "0" in v26.3.0 for very minor changes and fixes - such as "v26.3.0**a**", and so on ("v26.3.0**b**").
