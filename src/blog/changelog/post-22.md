Throughout March with versions 26.4.x, there have been a number of changes:

* **v26.4.0** involved updating the links page - removing the link to BlueSky.

* **v26.4.1** involved updating the site's colour scheme and beginning implementing navigational changes to the site, such as with implementing a drop down menu for "About Me" page and constituent page(s).

* **v26.4.2** involved implementing a new page - "My Vinted". In this version, it began as a work in progress (wip).

* **v26.4.3** involved a significant number of changes:
    * Updating the Vinted page
    * Updating the layout of the footer
    * Updating the hamburger menu layout
    * Added external link signifiers
    * Updates to terms and conditions
    * Fixes to the header, including alignment with the hamburger menu and desktop navigation.

* **v26.4.4** involved implementing a brand new homepage, in bento box style, with some minor tweaks and improvements made to it.

* **v26.4.5** involved fixing issues with the drop down menu in the header, for both desktop navigationa and for the hamburger menu.
    * As well, there were efficiency improvements and optimisations made to the homepage.
    * There were numerous fixes implemented for the website carbon badge.
    * New favicons were implemented across Brighton and Co - including a new TEST: Brighton and Co favicon.
